# ＶＡＰＯＲ ＰＬＡＹＥＲ 
Ретро MP3-плеер для Android в стиле vaporwave. Kotlin + Jetpack Compose + Media3.

Открыть папку в Android Studio (Koala+), дождаться Gradle Sync, Run.
minSdk 26, targetSdk 34.

Фичи: сканирование музыки устройства, фоновое воспроизведение + уведомление,
SLOW 0.8x (slowed-питч), таймер сна, шафл/повтор, избранное, поиск,
визуализатор, анимированная сетка + закат, CRT-сканлайны, окно в стиле Win95.
